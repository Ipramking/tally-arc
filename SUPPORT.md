# Support

Tally is a small open-source project, maintained by one person. Help is best effort, with no service level.

- **Using it:** start with [docs/getting-started.md](docs/getting-started.md); the API, library and on-chain details are in
  [docs/integrating.md](docs/integrating.md).
- **A bug, a wrong answer, or a question:** open an [issue](https://github.com/Ipramking/tally-arc/issues). Include the network,
  the contract address and what you expected. If a badge or the API shows a **higher** trust level than the evidence supports,
  that is a security issue: see [SECURITY.md](SECURITY.md) instead of filing it publicly.
- **Adding your chain:** open an issue with the chain id, RPC and explorer, or send the pull request described in
  [docs/getting-started.md](docs/getting-started.md#3-you-run-a-chain).
- **Guarantees:** the hosted studio and API are not promised to be up, and nothing here is an audit or a safety rating. If you need
  guarantees, [run your own copy](docs/getting-started.md#3-you-run-a-chain).
